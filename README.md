# STEAMLab — Pitágoras para pintar

Sitio para descargar un documento PDF de 2 páginas que contiene plantillas grande y pequeña para pintar el teorema de Pitágoras.

## Repositorio propuesto
`steamlab-pitagoras-para-pintar`

## Publicar en GitHub Pages
1. Accede a https://github.com/new con la cuenta **luisctito-sketch**.
2. Crea un repositorio **público** llamado exactamente `steamlab-pitagoras-para-pintar`.
3. Sube todos los archivos de este ZIP a la **raíz** del repositorio (index.html, PDF, vista-previa.png y QR). Haz clic en **Commit changes**.
4. En **Settings → Pages**, selecciona **Deploy from a branch**, rama **main**, carpeta **/(root)** y guarda.
5. Abre y comprueba que funcionan la imagen y el botón de descarga: https://luisctito-sketch.github.io/steamlab-pitagoras-para-pintar/
6. Imprime el código QR `QR_Cuaderno10_Pitagoras.png` y colócalo en el Cuaderno 10. El QR contiene la URL anterior, por lo que funcionará una vez publicada la página.

### Nota
El código QR se generó para la dirección propuesta, que no se ha verificado como publicada. No cambies el nombre del repositorio si ya colocaste el QR en el cuaderno.
